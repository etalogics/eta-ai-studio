Provider connection NOT CONNECTED

Higgsfield is the requested provider. This build has no live generation adapter and makes no paid requests.

Remaining integration requirements

  1. Confirm the approved provider and exact API model.
  2. Verify official authentication, upload, submit, status, result, and input capabilities.
  3. Add credentials to a local .env file using the verified scheme.
  4. Confirm whether the model supports multiple references and numbered prompt mentions.
  5. Approve a small paid smoke test before enabling live generation.

Cost estimates are optional in this milestone. An unavailable estimate will not block a future approved live adapter. Simulation costs $0.

Storage & runtime

SQLite stores drafts and history. Reference images are stored outside the public folder. The server binds to 127.0.0.1 and protects local API requests with a session and CSRF token.

Keep this application running to use it. Simulated status is recovered from saved timestamps after restart. See the README for backup and setup instructions.
